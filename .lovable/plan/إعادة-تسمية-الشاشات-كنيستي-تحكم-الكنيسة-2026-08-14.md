# إعادة تسمية الشاشات: كنيستي + تحكم الكنيسة

## الهدف
- شاشة الهوم القديمة (`/`) تصبح شاشة **كنيستي**.
- شاشة كنيستي الحالية (`/church`) تصبح شاشة **تحكم الكنيسة**.
- زر «تحكم الكنيسة» يظهر داخل شاشة كنيستي **للكاهن فقط** ويفتح شاشة التحكم.
- لا تصميمات جديدة، لا فيتشرز جديدة — بروتوتايب فرونت إند فقط.

## التغييرات

### 1. شاشة كنيستي (`src/routes/index.tsx`)
- تحديث عنوان الهيدر والـ `head()` إلى «كنيستي» بدل Church Home.
- إضافة زر واحد «تحكم الكنيسة» في الهيدر (نفس ستايل الأزرار الموجود، لون ذهبي/ink) يظهر فقط عندما `isPriest` صحيح.
- الزر عبارة عن `Link` إلى شاشة تحكم الكنيسة.
- باقي الأقسام كما هي بدون تعديل.

### 2. شاشة تحكم الكنيسة
- نقل `src/routes/church.tsx` إلى `src/routes/church-control.tsx` مع `createFileRoute("/church-control")`.
- تحديث النصوص: عنوان الشريط العلوي «تحكم الكنيسة» (بدل «كنيستك معاك») والـ `head()` (title / description / og).
- إضافة زر رجوع في الشريط العلوي يعود إلى `/` (يستبدل زر البحث أو يُضاف بجانبه — يُضاف بجانبه للحفاظ على التصميم).
- بقية التصميم والأقسام بدون تغيير.

### 3. الشريط السفلي (`src/components/church/BottomNav.tsx`)
- عنصر «كنيستي» يشير إلى `/` (شاشة كنيستي).
- حذف عنصر التنقل القديم لـ `/church`؛ عنصر «الرئيسية» يبقى شكليًا كما هو مثل بقية العناصر غير الموصولة.

## تفاصيل تقنية
- علم الدور: ثابت في الفرونت فقط، مثل `const isPriest = true;` داخل بيانات العرض في `index.tsx` (لا Auth ولا باكند).
- `src/routeTree.gen.ts` يتولد تلقائيًا بعد إعادة تسمية الملف.
- لا تعديل على `styles.css` أو مكونات الكروت.
